Initial release of the TechDocs Editor plugin suite for in-app documentation editing in Backstage. Includes classic and new frontend system support built on `@backstage/ui`, a WYSIWYG and Markdown editor with Mermaid diagram and media preview, a file tree panel, a Changes diff drawer, and local filesystem or GitHub/GitLab pull/merge request submission.
