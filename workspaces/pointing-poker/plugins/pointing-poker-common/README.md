# Pointing Poker Common

Shared types and the `TicketProvider` contract for the [Pointing Poker](../pointing-poker/README.md) frontend, backend and ticket-provider modules.

This package is not meant to be installed on its own. It is a dependency of `@backstage-community/plugin-pointing-poker`, `@backstage-community/plugin-pointing-poker-backend` and any backend module that adds an issue tracker.
