# Stack Overflow

This workspace contains plugins for integrating [Stack Overflow](https://stackoverflow.com/) content into Backstage. Use them to surface relevant questions and answers in search results or display them on the homepage.

## Plugins

- [stack-overflow](./plugins/stack-overflow/README.md): Frontend plugin that provides Stack Overflow search result items and a homepage widget for listing questions.
- [stack-overflow-backend](./plugins/stack-overflow-backend/README.md): Deprecated backend plugin. Use [`@backstage/plugin-search-backend-module-stack-overflow-collator`](https://github.com/backstage/backstage/blob/master/plugins/search-backend-module-stack-overflow-collator/README.md) instead to index Stack Overflow questions for search.
