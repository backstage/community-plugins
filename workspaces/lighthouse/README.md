# Lighthouse

This workspace contains plugins that integrate [Google Lighthouse](https://github.com/GoogleChrome/lighthouse) into Backstage, letting you run website audits and track their accessibility, performance, SEO, and best-practice scores over time.

## Plugins

- [lighthouse](./plugins/lighthouse/README.md): Frontend plugin to trigger Lighthouse audits on websites and track them over time.
- [lighthouse-backend](./plugins/lighthouse-backend/README.md): Backend plugin that supports automated, scheduled Lighthouse audit runs.
- [lighthouse-common](./plugins/lighthouse-common/README.md): Common types and functionalities to be shared between lighthouse and lighthouse-backend.
