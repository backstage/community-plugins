# XCMetrics

This workspace contains the Backstage integration for XCMetrics, a tool for collecting and analyzing build metrics from Xcode. The `xcmetrics` frontend plugin lets you view that build data directly inside Backstage.

## Plugins in this workspace

- [xcmetrics](https://github.com/Adesanmi1/community-plugins/edit/main/workspaces/xcmetrics/README.md#:~:text=CHANGELOG.md-,README,-.md) - Frontend plugin that adds an XCMetrics dashboard page to Backstage and exposes an API extension (`xcmetricsApiRef`) for fetching metrics from an XCMetrics backend instance.
