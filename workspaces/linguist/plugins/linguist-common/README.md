# Linguist Common

Common types, permissions, and constants for the Linguist plugin.

## Catalog Model Layer (alpha)

This package exports an alpha `linguistCatalogModelLayer` from `@backstage-community/plugin-linguist-common/alpha` that declares the `backstage.io/linguist` annotation for the [catalog model layer system](https://backstage.io/docs/releases/v1.50.0#catalog-model-layer-system-alpha-opt-in). It only has an effect if you have opted in to the model layer system in your catalog backend.
