# [Backstage](https://backstage.io)

# Badges

This workspace contains plugins for generating and displaying badges based on entity data from the Backstage catalog, such as owner and lifecycle information. Badges can be embedded outside of your Backstage deployment (e.g. in GitHub repositories).

## Plugins

- [badges](./plugins/badges/README.md): Frontend plugin that adds a badges context menu to entity pages and lets you copy badge markdown/URLs.
- [badges-backend](./plugins/badges-backend/README.md): Backend plugin that generates the badge SVGs via a configurable set of badge factories.
